# 技能根的生效条件

## 根内目录按 canonical 路径受限

发现器遍历根时，对每个目录取 canonical 路径，要求它落在某个根的 canonical 路径之内。落在之外的目录被丢弃，记一条 outside-root 诊断，且不再进入该子树。

两条推论：

- 根内的条目链接到根外目录时无效，逐条链进来同样无效。
- 根本身是链接时有效，因为根的 canonical 形式成为该根的基线。

## 接入一棵外部技能树

要让位于任意位置的技能树进入 catalog，只有两条完成路径：

1. 把该树的父目录设为根：根下直接是同名技能目录，而不是技能目录的再下一层。
2. 把树搬进或挂载进已有根，使其成为根内的真实目录。

## 加根前的核对

- 根列表若由函数计算，就没有可 setf 的变量；加根等于改该函数的返回。
- 先查设置项清单里是否已有可选目录类型的项可复用，再决定新增设置项，避免为一个目录造第二个开关。
- 根目录若兼作配置层，指向别处会让被取代的配置不再加载；加根前确认该根没有第二职责。

## 复核

配置或接线改动后，按名字解析目标技能，确认该根贡献了这个名字。诊断里出现 outside-root，说明链接被丢弃，根没生效。
